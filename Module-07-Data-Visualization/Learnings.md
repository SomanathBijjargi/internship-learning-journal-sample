# Key Learnings of the Module : 

* **reveal.js :** RevealJS is a **JavaScript-based HTML presentation framework** used to create interactive slides in a web browser.
* **Creating Presentations with Marp :** Marp allows you to create presentations directly from your text editor using Markdown.

* **Python Notebooks with Marimo** : Marimo is an open-source, reactive notebook for Python designed to solve common issues found in traditional notebooks, such as hidden state and reproducibility problems. 

* **Forecasting & Visualization in Excel: Time Series & Correlation Analysis :** Data visualization in Excel is a powerful way to explore time series data (such as currencies, indices, and commodities) and extract meaningful insights, trends, and forecasts.

* **RAWGraphs Visualization Reference Guide :** RAWGraphs is a free, open-source web-based data visualization tool designed to bridge the gap between spreadsheet applications and vector graphics editors

* **Seaborn Data Visualization Reference Guide :** Seaborn is a powerful Python data visualization library built on top of Matplotlib that provides a high-level interface for drawing attractive and informative statistical graphics
